## Are these resources enough?

| Track | Resource | Verdict |
|-------|----------|---------|
| **HLD** | This repo (docs + diagrams) | Enough for design rounds if you do **timed spoken** redesigns |
| **LLD** | [lld-practice](https://github.com/PSPenta/lld-practice) | Enough if you **code** designs, not only read |
| **DSA** | Blind 75 + ongoing LeetCode | Required; push past Blind 75 into Medium/Hard mix |
| **You** | Experience + ownership stories | Strong for Razorpay / fintech / backend SDE3 |

**Still add:** weekly mocks, behavioral/leadership STAR stories, company depth (payments/ledger/idempotency for Razorpay).

Resources get you interview-ready **content**. Offers need **execution under pressure**.

## Day window (11:00 – 21:00)

~10 hours total. Typical split: **office ~3h**, **lunch ~45m**, **breaks ~45m** → **~5.5h deep prep**.

| Time | Block | Focus |
|------|--------|--------|
| 11:00 – 11:15 | Warm-up | Plan day / revise yesterday mistakes |
| 11:15 – 13:15 | **DSA** (2h) | Timed problems → then review solutions |
| 13:15 – 14:00 | Lunch + walk | Off screens |
| 14:00 – 17:00 | **Office** (2–4h; default 3h) | Real work only — no LeetCode mix |
| 17:00 – 17:15 | Break | |
| 17:15 – 18:45 | **HLD or LLD** (1.5h) | Alternate per [weekly rhythm](#weekly-rhythm) |
| 18:45 – 19:00 | Break | |
| 19:00 – 20:30 | Second design track or DSA weak topic (1.5h) | See weekly table |
| 20:30 – 21:00 | Review / notes | Mistakes + 1 design takeaway |

**Flex**

- Office **2h** → add +1h DSA or +1h mock.  
- Office **4h** → keep evening design to ~1.5h total; protect sleep.

## Daily targets

| Track | Target |
|-------|--------|
| **DSA** | **2** timed problems (or 1 Hard + 1 Medium) + full solution review |
| **HLD** | **1** spoken redesign (40–50 min) **or** 1 doc deep-dive + redraw one flow |
| **LLD** | **1** design with code skeleton / interfaces in lld-practice |
| **Don’t** | Watch videos without redrawing / coding |

You won’t deep-dive all three every day — use the weekly alternate.

---

## Weekly rhythm

| Day | Morning (2h) | Evening (after office) |
|-----|----------------|-------------------------|
| **Mon** | DSA | **HLD** redesign (payments / queue / feed) |
| **Tue** | DSA | **LLD** + code |
| **Wed** | DSA | **HLD** (cache / search / chat) |
| **Thu** | DSA | **LLD** |
| **Fri** | DSA | **HLD** Staff extras (SLO, failure, cost) **or** mock |
| **Sat** | DSA 3h | HLD mock 1h + LLD 1h + weak DSA 1h |
| **Sun** | Light DSA 1h | **Behavioral / resume stories** 1h + rest / optional mock |

---

## Weekly targets

| Track | Weekly |
|-------|--------|
| **DSA** | **12–15** quality problems (Array/Hash/Tree/Graph/DP mix); 1 contest if possible |
| **HLD** | **4–5** full spoken designs from [Popular HLDs](../README.md#popular-hlds); 1 payments-style deep dive |
| **LLD** | **4–5** designs coded to a reviewable state |
| **Mocks** | **1** coding + **1** HLD (peer / Pramp / interviewing.io) |
| **Behavioral** | **3–5** STAR stories (migration, fraud cut, mentoring, conflict, failure) |

---

## 8–10 week phases

| Weeks | Priority |
|-------|----------|
| **1–3** | DSA past Blind 75; HLD: core docs + redesign all ✅ diagrams; LLD: top patterns |
| **4–6** | DSA Medium→Hard; HLD stretch (Uber, rate limiter, ID gen); LLD under timer; **weekly mocks** |
| **7–10** | Interview mode: ~60% DSA + mocks, ~25% HLD, ~15% LLD/behavioral; Razorpay: wallet/ledger/idempotency stories |

## Win condition

Weekly **mocks** + **spoken HLD** + **coded LLD** — not finishing every doc page.

Use [docs curriculum](./README.md) for HLD study order; practice from [diagrams](../diagrams/) and [Popular HLDs](../README.md#popular-hlds).
